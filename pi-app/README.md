# Pi app

This is the recorder that runs on the Raspberry Pi. It hasn't been started yet.

Planned pieces:

- **Audio engine:** 8 tracks for recording, playback and overdubbing, and
  per-track stem export as WAV files. Input comes from a USB audio device
  chosen in the app.
- **Screen UI:** 1280×400, drawn in code (shapes, text and waveforms), with
  images only for icons.
- **Controls:** the laptop keyboard stands in for the 24 keys until the
  control board is built.
